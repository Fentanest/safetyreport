# 나만의 안전신문고 (My Safety Report Manager)

안전신문고의 방대한 신고 내역을 내 컴퓨터나 서버로 가져와 **나만의 데이터베이스**로 구축하고, 강력한 **통계 분석 및 자동화 기능**을 제공하는 통합 관리 시스템입니다. 

단순히 기록을 쌓는 것을 넘어, 공공기관의 처리 품질을 분석하고 반복적인 업무를 자동화하여 스마트한 민원 관리를 지원합니다.

---

## ✨ 이런 기능들이 있습니다!

### 1. 🌐 언제 어디서나 접속하는 웹 UI
- 복잡한 명령어 없이도 깔끔한 **웹 브라우저 인터페이스**를 통해 모든 기능을 제어할 수 있습니다.
- 대시보드에서 현재 크롤링 상태와 실시간 로그를 한눈에 확인하세요.

### 2. 💻 다양한 환경 지원 (Windows, Linux, Docker)
- **윈도우**: 일반적인 PC 환경에서 간편하게 실행 가능합니다.
- **리눅스(데비안/우분투)**: 서버급 환경에서도 안정적으로 구동됩니다.
- **도커(Docker)**: 컨테이너 기술을 통해 복잡한 설정 없이 즉시 배포하고 관리할 수 있습니다.

### 3. 📂 내 손안의 빅데이터, 자동 아카이빙 및 검색
- 크롬 브라우저를 이용해 안전신문고의 모든 신고 내역(제목, 상세 내용, 답변 등)을 자동으로 DB화합니다.
- 안전신문고 웹사이트보다 훨씬 강력하고 유연한 **필터링 및 검색 조건**을 제공합니다.

### 4. 📊 시각적 통계 및 대시보드
- **기관별/담당자별 분석**: 어느 경찰서가 처리가 빠른지, 어떤 담당자가 수용률이 높은지 그래프로 확인하세요.
- **통합 대시보드**: 전체 신고 건수, 과태료 부과 비율, 진행 현황 등을 시각화하여 한눈에 파악할 수 있습니다.

### 5. ⭐️ 번거로운 업무는 끝, 일괄 별점 참여 (매크로)
- 수백 건의 완료된 신고에 대해 일일이 만족도 조사를 하실 필요가 없습니다.
- 원하는 별점(1~5점)을 선택하여 **한 번에 수십, 수백 건씩 자동 제출**하는 스마트 매크로 기능을 제공합니다.

### 6. 🚨 항상 눈여겨봐야 하는 '감시 목록' (Watchlist)
- 특별히 관리가 필요한 신고번호나 차량번호 등을 등록해 두면, 해당 건에 변화가 생겼을 때 빠르게 추적할 수 있습니다.

### 7. 📥 엑셀(Excel) 및 구글 스프레드시트 내보내기
- 수집된 모든 데이터를 서식이 잘 갖춰진 **Excel 파일**로 즉시 저장할 수 있습니다.
- **구글 스프레드시트**와 실시간 연동하여 팀원들과 협업하거나 모바일에서 바로 확인할 수 있습니다. (사진 미리보기 기능 포함)

### 8. 🤖 텔레그램(Telegram) 봇 비서
- 밖에서도 텔레그램 채팅 창을 통해 "크롤링 시작", "상태 조회" 등의 명령을 내릴 수 있습니다.
- 작업이 완료되면 결과 보고를 텔레그램 메시지로 즉시 전송해 드립니다.

---

## 🛠 왜 사용해야 할까요?

*   **데이터 영구 보존**: 안전신문고 웹사이트에서는 오래된 기록의 첨부파일 링크가 만료되거나 접근이 어려워질 수 있지만, 이 시스템은 모든 텍스트 데이터를 본인의 DB에 영구 보존합니다.
*   **행명 분석의 최적화**: 단순히 '답변을 받았다'에서 끝나는 것이 아니라, 어떤 기관이 적극적으로 불법을 단속하는지 숫자로 증명할 수 있습니다.
*   **시간 절약**: 매일 아침 수동으로 페이지를 넘기며 확인하던 시간을 획기적으로 줄여줍니다.

## 🚀 시작하기

### 1. Docker 환경 (추천)
- `docker-compose.yml` 파일을 작성한 후 `docker-compose up -d` 명령어 하나면 모든 준비가 끝납니다.

### 2. 설정
- 웹 인터페이스의 **[설정]** 메뉴에서 로그인 계정, 텔레그램 토큰, 구글 API 키 등을 간편하게 입력할 수 있습니다.
