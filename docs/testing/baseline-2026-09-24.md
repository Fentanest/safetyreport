## 1. Python unittest
| 시점 | 명령 | 결과 |
|---|---|---|
| 변경 전 코드(17df6cb), 공용 venv | `python -m unittest discover -s tests -p "test_*.py"` | **7/7 통과** (geocode 6, reset 1) |
| 변경 전 코드, 메인 checkout 로컬 전용 `tests/test_db_backup_regression.py`(미추적) | importlib 로 단독 실행 | **1/1 통과** |

주의: 기존 unittest 는 `settings` import 시 `<repo>/data/` 를 만들고 로그 디렉터리를 쓴다. 데이터 분리가 필요하면 `SAFETYREPORT_DATA_DIR` 를 준다.
seam 작업 중 기존 geocode 회귀 테스트가 내 실수(import 누락)를 잡았다 → 수정 후 통과.
