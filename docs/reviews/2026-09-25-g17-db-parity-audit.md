## 남긴 것
- 1회성 데이터 복구(서버 차량번호 복구)는 서버 기동 때만, 모바일은 v15 마이그레이션 때만 돈다. 교환(가져오기·복원)은 값을 바꾸지 않는다 — 왕복 검사가 무손실을 확인하기 위해.
- 계산 동등성 검사는 통계·대시보드만 다룬다. 중복군 재계산·파서는 공용 벡터·개별 테스트로 확인한다.
