**나만의 안전신문고** v3.3.0

### 새 기능
- 모바일 앱의 서버 연결 모드에서 신고 검색을 서버에서 처리하는 기능을 추가했습니다. 모바일 앱 새 버전과 함께 쓰면 검색과 페이지 이동이 빨라집니다.

### 개선
- 위반 조항별 법정 금액을 대조해 과태료 금액의 오타를 바로잡는 범위를 넓혔습니다.

### 버그 수정
- 지역명이 붙은 이륜차 번호판을 인식하지 못하던 문제를 고쳤습니다. 같은 차량의 신고를 찾고 추정 과태료를 계산할 때 반영됩니다.

### 업데이트 안내
- 모바일 앱도 2.2.0으로 업데이트하면 서버 연결 모드에서 더 빠른 신고 검색을 이용할 수 있습니다.
