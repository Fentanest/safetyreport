**나만의 안전신문고** v3.4.0

### 새 기능
- 답변에 위반법규가 여러 개 적힌 신고는 법규를 모두 저장하고, 검색·통계·상세 링크를 법규별로 나눠 볼 수 있습니다.
- 신고 상세의 "원본 응답"에서 안전신문고 상세 응답 원본(신고자 정보 제외)을 보고 검색·복사·다운로드할 수 있습니다. 파일 탐색기의 `raw_details` 폴더에도 신고별 JSON 파일이 남습니다.
- 업데이트 뒤 기존 신고를 새 규칙으로 다시 읽는 DB 최적화가 백그라운드에서 한 번 진행됩니다. 진행 상황과 단계 로그는 화면 하단 표시줄에 보입니다. 앞으로 파싱 규칙이 바뀌는 업데이트에서도 같은 방식으로 자동 갱신됩니다.

### 개선
- 위반법규 인식(약칭·괄호·가지번호와 항 구분)과 답변의 확정 과태료 금액 인식을 넓혔습니다. 조건부·감경 후 금액처럼 확정되지 않은 금액은 확정 금액으로 저장하지 않습니다.
- 통계의 위반법규 막대 건수와 막대를 눌렀을 때 열리는 목록 건수를 맞췄습니다.
- 같은 PC의 리버스 프록시(cloudflared·Caddy 등) 뒤에서 기본 설정으로 동작하고, 예전 `trusted_proxies` 값 때문에 서버가 시작되지 않던 경우를 막았습니다.

### 버그 수정
- 완료된 신고의 처분이 비어 있거나 미확인으로 남던 경우 답변에 적힌 과태료 부과를 반영합니다. 경고·계도로 끝났거나 "다시 적발되면" 같은 조건 문장은 과태료로 보지 않습니다.

### 업데이트 안내
- 이전 DB를 비우지 않고 새 구조로 올립니다. 올리기 전에 `data/backups` 에 자동으로 백업합니다.
- 업데이트 직후 DB 최적화가 기존 신고의 상세를 한 번 다시 받아 원본을 채웁니다. 신고 수에 따라 시간이 걸리며, 그동안 시작한 크롤링은 최적화가 끝난 뒤 이어서 진행됩니다. 로그인이 필요하거나 네트워크가 불안정하면 최적화는 잠시 쉬고 크롤링은 그대로 진행됩니다.
- 마지막 크롤링 이후 새 답변이 온 신고는 일반 크롤링에서 처리되므로 변경 알림은 평소처럼 받습니다.
- 모바일 앱도 2.3.0으로 함께 업데이트해 주세요. 서버 연결 모드의 법규별 검색·원본 응답 보기는 두 버전이 모두 필요합니다.
