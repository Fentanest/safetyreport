**나만의 안전신문고** v3.5.0

### 새 기능
- 통계에 **전체** 분류 탭이 생겼고 처음 열면 전체가 선택됩니다. 모든 분류의 신고를 합쳐 기관별·담당자별 표, 위반법규 선택 목록, 지도, CSV를 볼 수 있습니다. 확정 과태료와 추정 과태료는 전체 탭에서도 따로 보입니다.

### 개선
- 리버스 프록시 설정이 맞지 않아도 웹 화면이 동작합니다. `trusted_proxies` 를 비워 두면 같은 PC·Docker·LAN·Tailscale 의 프록시를 자동으로 신뢰하고, 설정을 저장하면 재시작 없이 바로 반영됩니다. 설정 화면에 지금 연결이 어디서 오는지와 신뢰 여부가 표시됩니다.
- 잘못된 전달 헤더가 와도 요청 전체를 막지 않고 그 헤더만 무시합니다.
- 기관코드 자료를 2026-10-18 공식 자료로 갱신했습니다(2026-10-01 검찰청→공소청 개편 등).

### 버그 수정
- Docker 포트 매핑 뒤(호스트의 cloudflared 등)에서 `trusted_proxies` 가 실제 프록시 주소와 다르면 크롤링 시작·설정 저장 등 웹 화면의 저장·실행 버튼이 모두 `csrf_failed`(403)로 막히던 문제를 고쳤습니다. 모바일 앱 서버 연결 모드는 원래 영향이 없었습니다.
- https 주소로 접속했을 때 일부 화면 스크립트나 이동 주소가 http 로 내려가던 경우를 막았습니다.
- 통계 담당자 행을 눌러 연 목록이 그 담당자의 신고만 정확히 보이도록 했습니다. 이름이 같은 다른 기관·`(구)` 기관도 통계 표와 같은 기관 기준으로 엽니다.
- 서로 다른 기관이 통계에서 한 기관으로 합쳐지던 문제를 고쳤습니다(예: 서울중앙지검과 부산지검, 국세청과 관세청, 해양경찰청). 일부 중앙부처·검찰 계열 기관의 통계 묶음이 바로잡히며, 일반 경찰서와 시·군·구는 바뀌지 않습니다.

### 업데이트 안내
- DB 구조 변경은 없습니다.
- 예전 `trusted_proxies` 값이 남아 있어도 화면은 동작합니다. 접속 주소·https 판정을 정확히 하려면 앱 설정에서 그 칸을 비우고 저장하세요(자동 신뢰).
- 모바일 앱 2.4.0 에서 통계 전체 탭과 통계 카드 → 목록 정확 일치를 쓰려면 서버도 이 버전이 필요합니다. 이전 앱은 그대로 동작합니다.
