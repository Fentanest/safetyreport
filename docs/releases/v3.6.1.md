- 업데이트하거나 프로그램을 다시 켠 직후, 필수 설정 화면이 "확인 중"에 머물러 새 공유 동의문이 나오지 않던 문제를 고쳤습니다. 이전에는 "상태 다시 확인"을 눌러야 동의문이 보였지만, 이제는 확인이 끝나는 대로 화면에 자동으로 나옵니다.
