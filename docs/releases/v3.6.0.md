**나만의 안전신문고** v3.6.0

> 3.6.0으로 올린 직후 필수 설정 화면에 새 동의문이 바로 뜨지 않던 문제는 3.6.1에서 고쳤습니다. 3.6.1 이상으로 업데이트해 주세요.

### 업데이트 후 처음 열면
- 커뮤니티 지도 공유 동의문이 바뀌어 필수 설정 화면에 새 동의문이 나옵니다. 읽고 동의하면 바로 이어서 쓸 수 있습니다. 카카오 로그인과 이 PC의 신고 기록은 그대로입니다.
- 동의하면 답변이 끝난 내 신고를 지도에 한 번 다시 보냅니다. 보내기 전에 빠져 있던 신고와 별점·사진 촬영 시각을 안전신문고에서 다시 받아 채웁니다. 진행 상황은 신고 지도 탭의 "원본 전송 n / N"에서 볼 수 있고, 크롤링이 있으면 크롤링이 먼저 진행됩니다.

### 달라진 점
- 지금까지는 앱이 처리 결과만 골라 보냈지만, 이제 신고·답변 내용을 지도 서비스가 직접 읽어 정리합니다. 신고를 읽는 규칙이 좋아지면 다시 보내지 않아도 지도에 반영됩니다.
- 내 이름·이메일·전화번호·아이디와 안전신문고 로그인 정보는 보내지 않습니다. 받은 신고 내용은 비공개로 보관하며, 다른 사람에게 보이는 정보는 이전과 같습니다.
- 공유에 동의해야 앱을 쓸 수 있습니다. 인터넷이나 서버 문제로 확인이 안 될 때는 마지막 확인 뒤 3일까지 그대로 쓸 수 있습니다(그동안 지도로는 보내지 않음).
- 동의를 철회하거나(이 PC·다른 기기 어디서든), 카카오에서 앱 연결을 끊거나 카카오를 탈퇴하면 카카오 로그인부터 다시 시작합니다. 신고 기록은 지워지지 않고, 같은 카카오 계정으로 다시 동의하면 이어서 씁니다.

### 고친 점
- 안전신문고 계정을 처음 입력해 저장할 때도 "계정 변경" 경고가 뜨던 문제
- DB 최적화 중 만족도 조사를 마친 신고마다 "조회 실패" 경고가 로그에 남던 문제(저장된 값은 바뀌지 않았습니다)

### 알아 두기
- 신고 DB는 바뀌지 않고, 커뮤니티 공유 기록만 자동으로 새 구조로 바뀝니다.
- 이전 버전은 새 동의 뒤에도 예전 방식으로 보냅니다. 예전 방식은 일정 기간 뒤 중단할 예정이며 날짜는 따로 알리겠습니다.
- 모바일 앱도 2.5.0으로 함께 업데이트해 주세요. 서버 연결 모드는 PC와 모바일이 모두 새 버전이어야 같은 규칙으로 동작합니다.
