**나만의 안전신문고** v3.1.3

### 버그 수정
- 커뮤니티 서버 이전 뒤 신고 공유 업로드와 '신고 내역 다시 불러오기'가 서버에 닿지 못해 시작되지 않던 문제를 고쳤습니다.
- 커뮤니티 서버 이전 전의 설정이 남아 있는 PC에서 커뮤니티 로그인이 '연결 정보를 찾을 수 없음'으로 끝나던 문제를 고쳤습니다. 이전 설정은 업데이트 후 처음 실행할 때 자동으로 백업하고 정리합니다.
- Docker에 이전 커뮤니티 서버 설정이 남아 있는 경우에도 업데이트에 포함된 새 연결 설정을 사용합니다.
- '신고 내역 다시 불러오기'를 시작하지 못했을 때 '시작 조건을 확인해 주세요' 대신 무엇을 해야 하는지 알려 줍니다. 모바일 앱의 서버 연결 모드에서도 같은 안내가 보입니다.
- 다시 불러오기 중에 커뮤니티로 올린 자료의 건수를 기록에 남깁니다. 이전에는 '전송 0건'으로만 보여 올라가지 않은 것처럼 보였습니다.
- 통계의 별점 옆 숫자를 '명'이 아니라 '건'(평가된 신고 수)으로 표시합니다.

### 업데이트 안내
- 업데이트 후 커뮤니티 계정에서 카카오로 한 번 다시 로그인해 주세요.
