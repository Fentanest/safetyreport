**나만의 안전신문고** v3.5.1

### 버그 수정
- 같은 기관이 부서 코드에 따라(예: `서울강서경찰서` / `…서울강서경찰서 경비교통과` / `…교통과`) 화면마다 다른 이름으로 보이던 문제를 고쳤습니다. 대시보드(감시 목록·최근 답변), 감시목록, 자동 별점, 중복 차량, 중복 신고 관리 상세, 텔레그램 신고 메시지가 신고 목록·통계와 같은 현행 기관명을 보입니다. 통계 집계는 원래부터 한 기관으로 묶여 있었고 바뀌지 않습니다.

### 개선
- 크롬 확장이 같은 기관의 담당자를 하나로 묶고 현행 기관명을 보일 수 있도록, 차량·주소 검색과 요약 API 응답에 현행 기관명·기관 키를 추가했습니다(크롬 확장 1.2.6 이상에서 적용). 기존 응답 값은 그대로입니다.
- 모바일 앱 알림이 현행 기관명을 보일 수 있도록, 변경 알림 자료에 기관코드와 현행 기관명을 추가했습니다.

### 업데이트 안내
- DB 구조 변경은 없습니다. 저장된 원래 기관명은 바뀌지 않으며, DB 편집기·원본 보기·자동 Excel/Google 시트 내보내기는 원래 이름을 그대로 씁니다.
- 이전 버전의 모바일 앱과 크롬 확장도 그대로 동작합니다.
