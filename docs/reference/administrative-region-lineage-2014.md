# 2014년 이후 시도·시군구 지역코드 계보 대조

조사일: 2026-09-28. 이 문서는 **처리기관 소속 지역 → 기관 → 담당자** 통계의 지역 단계에 사용할 조사 결과다. 제품 코드에 적용된 규칙은 아니다. 전체 법정동 코드 원본에서 추린 [2014년 이후 코드 목록](administrative-region-codes-2014.md), 폐지 코드별 [지역 계보 CSV](administrative-region-lineage-2014.csv), [공식 변경 공지 목록](administrative-region-notices-2014.csv)을 함께 본다. CSV의 지역코드는 앞자리 0을 보존하는 문자열이다.

## 조사 범위와 대조 방법

- [행정표준코드관리시스템 법정동코드 전체자료](https://www.code.go.kr/stdcode/regCodeL.do)의 2026-09-28 스냅샷에서 **시도·시군구 수준**의 2014-01-01 이후 폐지 코드 74개와 이 기간에 생성된 현존 코드 79개를 추렸다. 폐지 코드마다 현재의 후속 지역 또는 계속 쓰이는 상위 지역을 연결했다. **74/74개의 관계를 분류**했으며, 연결 결과는 공식 코드표의 이름·부모·일자와 [코드변경 안내](https://www.code.go.kr/bbsmng/dataBbsL.do), 설치 법률·지자체 자료로 대조했다. 같은 이름의 지역이라도 코드는 독립적으로 기록했다.
- 게시판에서 `법정동`으로 검색되는 2014년 이후 공지 74건의 제목·일자·첨부 링크·첨부 SHA-256을 CSV로 저장했다. 73개 첨부를 내려받았고 2018년 울주군 공지(번호 3183) 첨부는 HTTP 200의 빈 응답이었다. 2023년 강원·2024년 전북 등의 상위 개편은 게시판 검색만으로 포괄되지 않으므로 공식 코드표와 법률도 사용했다. 내려받은 바이너리는 조사용 `.agent-runs/`에만 있다.
- 현존 신규 코드 79개 중 73개는 폐지 코드의 후속 지역이다. 나머지 **6개는 새 하위 구역**으로, 2014년 청주시 서원구·청원구와 2026년 화성시 만세구·효행구·병점구·동탄구다. 옛 청원군의 목적지는 기존 청주시 코드 `4311000000`이므로 후속으로 참조된 현존 코드의 고유 개수는 74개다.
- 법정동 전체 코드의 읍면동·리 변화도 원본 목록에 보존했으나, 아래 계보의 단위는 시도·시군구다. 이 통계의 지역은 신고 발생지가 아니라 **답변 처리기관의 소속 행정구역**이므로 읍면동별 분배를 자동 추정하지 않는다.

계보 CSV의 `old_region_closed`는 공식 코드표의 폐지일이고 `effective_date`는 **연결 대상이 생긴 사건의 시행일**이다. 부천의 `effective_date=20240101`은 재설치일이며 옛 구의 폐지 시행일은 아래 표에 따로 적었다. 날짜가 어긋나는 자료를 자동으로 같은 날로 보정하지 않는다.

## 자동으로 확정할 수 없는 것

1. **분할 전 기관의 과거 소속**: 옛 인천 중구·서구의 처리기관코드와 지역코드만으로 그 신고를 신설 구 중 하나에 배정할 수 없다. 해당 옛 지역과 옛 기관을 `(구)`로 표시하고 현재 인천시 합계에 한 번만 넣는다. 청원군은 현행 청주시 합계에 넣되 하위 행을 `(구)청원군`으로 둔다. 새 구별 집계에는 포함하지 않는다.
2. **하위 구역이 없던 기간**: 부천시의 2016–2023년 처리건과 화성시 2026-02-01 이전 시청 처리건은 현행 구별로 소급 배분하지 않는다. 부천의 옛 구청과 2024년 재설치 구청을 *같은 기관 통계 키*로 묶을지는 지역코드 계보만으로 결정하지 못한다.
3. **지자체 기관코드 계승**: [공식 기관코드 전체자료](https://www.code.go.kr/stdcode/orgCodeL.do) 2026-09-28 ZIP과 대조하면 위 범위의 폐지·신설 시도·시군구 지역코드 **153개 모두** 같은 전체기관명을 가진 지자체 기관코드가 있다. 그러나 해당 기관코드 행의 `이전기관코드`는 **전부 `NULL`**이다. 따라서 지자체는 `이전기관코드`만 따라서는 개명·통합을 연결할 수 없다. 예: 청주시 `4360000`+청원군 `4410000`→통합 청주시 `5710000`; 인천 중구청 `3490000`→영종구청 `3491000`·제물포구청 `3501000`의 관할 분할. 새 기관코드의 생성일이 시행일보다 앞설 수도 있으므로 지역 사건의 **시행일**과 답변일을 따로 대조한다.
4. **코드가 유지된 경계·이름 변경**: 현재 코드표 한 장에는 같은 코드의 과거 명칭·관할구역 스냅샷이 없다. 2014년 청주시 지역코드 `4311000000`은 유지됐지만 구청 기관코드는 새로 발급됐고 구 경계가 바뀌었다. 다른 기관(경찰·공기업 등)의 기관코드 계보 전수 검증도 이 표에 포함되지 않는다. 따라서 **지역코드 74/74개 연결이 모든 기관 통계의 자동 일원화를 뜻하지는 않는다.**
5. **원본의 날짜 누락**: 전체 법정동 코드표에는 폐지일 미상 코드 171개가 있다. 시군구 수준에서는 옛 여주군 `4173000000` 1개가 여기에 해당한다. [여주시 설치 법률](https://www.law.go.kr/LSW/lsRvsDocListP.do?chrClsCd=010202&lsId=011870&lsRvsGubun=all)의 시행일이 2013-09-23이므로 2014년 이후 계보 74개에는 넣지 않았다. 다른 170개는 하위 지역이며 폐지 시점을 원본만으로 확인할 수 없다.

### 가져온 DB에 해당하는 범위

`issue/backup_data_1790558150366.db`의 `reports` 6,208행을 **읽기 전용**으로 집계했다. 처리기관명이 옛 광주광역시·전라남도로 시작하는 지자체 신고는 각각 1,128·2,189건, 현행 전남광주통합특별시로 시작하는 지자체 신고는 756건이다. 경찰청 광주광역시경찰청·광주경찰청·전라남도경찰청·전남경찰청으로 시작하는 신고는 각각 548·897·371·117건이다. 이 이름들은 위 통합 사건의 대조 대상이다. 인천 중구·서구, 청원군, 부천 세 구, 화성시라는 **정확한 지역명 문자열**이 처리기관명에 들어간 행은 없었다. 처리기관 공란은 172건이며 원본 DB에는 기관코드 열이 없으므로 이 건들과 과거 신고의 공식 기관코드를 확정했다고 보지 않는다.

## 통계에 적용할 규칙

- 지역 사건을 `옛 지역코드 → 새 지역코드(들), 시행일, 관계, 근거`로 버전 관리한다. **1:1 이동**은 새 지역으로 합산하고, **다:1 통합**은 새 지역의 합계에 합산한다. 서로 다른 기관을 지역 합산만으로 같은 기관 ID로 합치지 않는다.
- **1:다 분할**은 옛 지역을 독립 역사 노드로 유지하고 이름 앞에 `(구)`를 붙인다. 옛 기관도 후계 기관 한 곳을 임의 선택하지 않는다. 역사 노드는 현행 상위 지역 합계에 한 번만 반영한다. 같은 방식은 통합 뒤 구별 배분이 불가능한 `(구)청원군`에 적용한다.
- `이전기관코드`가 있는 경찰 등은 기관 단위 1:1 연쇄로 추적한다. 지자체 기관처럼 공란인 경우에는 **검증된 지역 사건과 기관명·상위 경로·답변일**로 대응 후보를 만들되, 분할·재설치·기관 통합은 별도 확정 규칙이 필요하다. 기존 신고의 원문 기관명과 앞으로 수집할 기관코드는 덮어쓰지 않는다.
- 이번 CSV는 조사용 사건표다. 앱/커뮤니티 맵에 넣기 전에는 각 기관 수준의 계보와 날짜 경계를 검증하고, 새 코드가 나타날 때 미해결 사건을 탐지하는 빌더가 필요하다. 구현 계획은 [기관 계보 계획](../plans/agency-lineage-registry.md)에 둔다.
